# ⌚ ServeSync Wear - Wear OS Companion

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)
![Wear OS](https://img.shields.io/badge/Wear_OS-4285F4?style=for-the-badge&logo=wearos&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)

**ServeSync Wear** es la aplicación complementaria diseñada específicamente para smartwatches con **Wear OS**. Forma parte del ecosistema **ServeSync**, permitiendo que el personal de servicio reciba notificaciones críticas y consulte el estado de las mesas directamente desde su muñeca, sin necesidad de sacar el teléfono.

---

## 🚀 Características Principales

*   **🔔 Notificaciones en Tiempo Real:** Recibe alertas instantáneas cuando una mesa solicita la cuenta o requiere atención.
*   **📊 Mapa de Mesas Rápido:** Consulta de un vistazo qué mesas están ocupadas, libres o en proceso de pago.
*   **🔄 Sincronización en la Nube:** Conectado directamente a **Firebase Firestore** para asegurar que la información esté actualizada en milisegundos entre la tablet de caja y el reloj.
*   **🔋 Optimizado para Wear OS:** Interfaz diseñada para pantallas circulares y de bajo consumo de batería.

---

## 🛠️ Stack Tecnológico

*   **Framework:** [Flutter](https://flutter.dev) (Multi-plataforma).
*   **Backend:** [Firebase](https://firebase.google.com) (Firestore & Auth).
*   **Plataforma:** Wear OS 3.0+ (Android).

---

## 📦 Instalación y Configuración

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/pokyto69/app_nueva.git
    ```
2.  **Obtener dependencias:**
    ```bash
    flutter pub get
    ```
3.  **Configurar Firebase:**
    *   Asegúrate de incluir tu archivo `google-services.json` en `android/app/`.
4.  **Ejecutar en un emulador o dispositivo físico:**
    ```bash
    flutter run
    ```
